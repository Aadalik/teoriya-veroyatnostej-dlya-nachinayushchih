<h2>Пространство элементарных исходов: без него не работает ни одна формула</h2>

<p>Прежде чем считать вероятность, нужно определить, что именно считается &laquo;исходом&raquo;. Элементарное событие &mdash; это результат опыта, который может наступить один и только один раз в рамках испытания. Пространство элементарных исходов &mdash; множество всех таких событий.</p>

<p><strong>Пример с монетой.</strong>&nbsp;При одном броске пространство исходов: {орёл, решка}. При двух бросках: {ОО, ОР, РО, РР} &mdash; четыре элементарных исхода.</p>

<p>Ошибка новичка &mdash; считать исходом то, что исходом не является. Например, при броске кости &laquo;выпало чётное&raquo; &mdash; это не элементарный исход, а событие, объединяющее три исхода: 2, 4 и 6. Путаница на этом уровне приводит к неверным расчётам.</p>
